Adding/Editing Content: Basics

Editing Existing Content

Pages are found under Pages or Posts in the left-hand sidebar navigation.

Getting to the Editing View

Navigate to the correct section and find your page by scrolling or using the search bar. Click the page title to open the editing view, or hover over it and click Edit.

Adding a New Page

Head to the appropriate section (Pages or Posts) and click the small Add New button beside the section title.

Adding a Blog Post

Same process as above. Head to the Posts section and click the small Add New button beside the section title.

Blog Post Categories

Categories keep posts organized and easy to navigate.

Adding a New Category
  1. Go to Posts → Categories in WP-Admin.
  2. Enter a Name (how it appears on the site) and Slug (URL-friendly version — auto-generated if left blank).
  3. Optionally set a Parent Category for subcategories.
  4. Click Add New Category.
Setting a Default Category

Go to Settings → Writing and select the Default Post Category from the dropdown. All new posts are automatically assigned this category.

Assigning a Category to a Post
  1. Open the post, then open the post settings sidebar.
  2. Scroll to Categories and check the box next to the category you want.
  3. Click Save.

Titles vs. Permalinks

When you create a page, WordPress auto-generates a permalink (slug) from the title. Once set, the permalink stays the same even if you change the title — meaning the two can differ intentionally.

Example: the URL is kickpoint.ca/newsletter/ while the page title reads A Newsletter You'll Actually Read.

ImportantPermalinks/Slugs should stay the same once you’ve published a post or page because it’s a major part of how visitors find your content. Changing a permalink can cause broken links and a loss of traffic. However, page titles can be changed as needed.

Saving Your Work

At the top of the right of the screen for all new or in-progress pages and posts, you will see three options: Save Draft, Preview, and Publish.

Save Draft

Saves your content without publishing it. Use this to save progress or return to a page later.

Publish

Saves and makes your content live. Visibility options:

  • Public — live to all visitors (default)
  • Private — visible only to admin-level users
  • Password protected — requires a password to view

You can set a publish date in the past (backdate) or schedule for the future. After the first publish, this button changes to Update.

Note Published too soon? "Switch to draft" will appear where "Save Draft" was — click it to unpublish.

Preview

Opens a new tab showing what the page would look like if published. Use this to check formatting before committing.

Templates

Set page templates in the Page Summary sidebar. For most new pages, leave the template as Default.

Available Templates

  • Default — Most flexible; use for the majority of pages. Automatically adds a banner block.
  • About — Same as Default, plus About page schema and an intro text block below the banner.
  • Contact — Shows contact info on the left and a contact form on the right. (Please note: your current contact page uses the default template)
  • Landing — For Google Ads landing pages. Removes the main navigation menu.
  • Pillar — Adds a sticky sidebar table of contents for long-form content.

Adding a Pillar Page

The Pillar template creates a sticky sidebar table of contents.

To build one:

  1. Add a Section Heading block — this text appears as a link in the sidebar TOC.
  2. Add content blocks below it as needed.
  3. Repeat for each new section.
Note If you want the sidebar link text to differ from the on-page heading, use the Alternative Heading field in the Section Heading block settings.

Setting a Parent Page

Setting a parent page establishes a hierarchy — for example, About Us as parent and Our Team as a child page. Set this in the Page Attributes sidebar.

Setting a Parent Page helps establish a page hierarchy on your site by grouping pages together under a single ‘top-level’ page to organize your website. This usually corresponds to how you want the page to appear in the website’s navigation menu.

To set a Parent Page, select the appropriate page from the Parent drop menu. If you do not, your page will default to having no parent, which means it will be treated as a ‘top-level’ page by WordPress.

Territory Map & Hot Markets

The Available Territories page uses two separate tools: an interactive territory map plugin, and a row of “Hot Markets” buttons that link out to individual city pages.

Territory Map (USA Map Plugin)

The interactive map on the Available Territories page (bintheredumpthatfranchise.com/available-territories/) is generated by USA Map, a paid mapping plugin. It is placed on the page with a shortcode rather than a content block:

[usahtml5map id="1"]

You shouldn’t need to edit this shortcode — it always points to the same saved map (ID 1). Territory boundaries, colors, and labels are managed from the USA Map plugin’s own settings screen in the WordPress admin, not from the page editor.

Hot Markets

Below the map, the Hot Markets section lists a row of buttons linking to individual city pages. Each button is added as raw HTML in the block rather than the standard button block.

Removing a city: delete that city’s button code from the Hot Markets block.

Adding a city: first create the page you want to link to, then add a new button using the code below, updating the bold placeholders with the page URL and city name:

<p style="text-align: center;"><a class="btn" href="/page-url">CITY NAME</a></p>

Reusable Blocks (Patterns)

Create a Reusable Block

  1. Select the blocks you want to reuse.
  2. Click the three-dot menu → Create pattern.
  3. Name it. Optionally assign a category.
  4. Choose Synced (edits propagate everywhere) or Unsynced (edits apply only to that instance).
  5. Click Create.

Edit a Reusable Block

Go to Appearance → Patterns, find your pattern, and click the pencil icon. Save when done — synced patterns update everywhere they're used.

Detach a Reusable Block

Select the pattern on a page → click ⋯ in the toolbar → Detach. Converts that instance to unsynced, leaving the original untouched.

The Link Pop-up

Adding a Table

Your website uses TablePress to create and manage tables. You can add the tables wherever needed using the “table” block.

Creating a New Table

Create and manage tables by going to the “TablePress” screen in the admin menu (pictured below).

  1. Go to TablePress → Add New.
  2. Give the table a name and specify the dimensions of your table (number of rows & columns)
  3. Start filling out the individual cells of your new table. The interface you use to fill out the table is simple and uncomplicated and is somewhat akin to your average Excel spreadsheet.
    • On this page, your table will be assigned an ID and a shortcode you’ll use to add the table to your post or page.
  4. Further down on the same page, you can find some basic options, like inserting links/images in your cells, duplicating/deleting selected rows and columns, combining cells, alternating colour by row, enabling sorting/pagination, and more.
    • The plugin automatically assumes that your first row is the header row for the table, but you do have the option to prevent that and even change the last row to a table footer.
  5. Click the “Save Changes” button, then the “Preview” button at the bottom of the page to get a basic idea of what your table will look like when inserted in a post or page.
NoteWe recommend turning "off" all options under Table Features for Site Visitors.

Importing a Table

If you’ve already got your data ready (such as an Excel sheet or Google Sheets document) and waiting to go in an external format, you can import it right into the TablePress plugin.

  • Navigate to WP Admin > TablePress > Import a Table
  • On this page, you’ll select your import source.
  • Once you click the “import table” button, you’ll be redirected to the same editing page as when you created your table from scratch. Except for this time, the table name, description, and content have already been filled in. All that remains to do is customize the options down at the bottom.

Inserting a Table into a Page

To show one of your tables on a page or post, you can do either of the following:

  1. Use the “table” block and add your table ID.
  2. Insert [table id= /] into the intro text or regular text block.

Each table has a unique ID that needs to be adjusted in the content block or the Shortcode. You can find this code by hovering over the TablePress menu and selecting “Show Shortcode”. Grab this code and copy/paste it into the shortcode content block.

Adding a Button

You can add a button to the text editor of any block by adding this shortcode and adjusting the text in bold below:

[kpbutton href="URL HERE" class="btn" target="_blank"]Button Text[/kpbutton]
  • href — Enter the URL you are linking to in between the quotation marks.
  • target="_blank" — If you’d like the link to open in a new window enter _blank in between the quotation marks. If you’d like the link to open in the same window enter _self in between the quotation marks.
  • Button Text — This is the text that will appear on the button.

Appendix: Title Tags & Meta Descriptions

Page Titles

Be compelling and include your target keyword(s). Keep titles between 40–60 characters so Google doesn't truncate them. Use Title Case. Use Moz's Title Tag Preview Tool to preview how your title will appear in search results.

Meta Descriptions

Don't directly affect rankings, but a well-written description improves click-through rates. Guidelines:

  • Under 300 characters
  • Include what the page offers and a call to action
  • Unique for every page
  • Active voice; include keywords naturally

Determining Keywords

  1. Think about what someone would Google to find this specific page.
  2. Search those terms and study the top results. What are they doing well?
  3. Check "Searches related to…" at the bottom of the Google results page for additional keyword ideas.
  4. Weave keywords naturally into the title and page content — don't force awkward phrasing.
  5. Target different keywords on different pages. Don't compete against yourself.

Appendix: Adding Redirects

Redirects are managed under Tools → Redirection.

Redirect a Removed Page

  1. In Add New Redirection, enter the removed page's path in Source URL.
    Example: strip the domain from https://yoursite.com/case-studies/ → enter /case-studies/
  2. Enter the full destination URL in Target URL.
  3. Click Add Redirection.

Redirect for an Updated Permalink

When you change a page's slug, the Redirection plugin creates the redirect automatically.

Vanity URL Redirect

The Source URL doesn't have to be a real page — just make sure it doesn't conflict with an existing URL.

Avoid redirect chains Search for existing redirects before creating new ones. Chains (A→B→C) slow page loads and hurt SEO. If a chain exists, update the first redirect to point directly to the final destination.
